# ศิษย์สำนัก — ศูนย์กลางเครือข่ายลูกศิษย์ ผศ.ดร.อำนาจ บุญอนนท์ และคลังวิชา

รุ่น 1.2 · ธีมทอง-ขาว · PWA แบบ static (HTML + CSS + Vanilla JS ไม่มี build step) ยกสถาปัตยกรรมจากระบบบริหารจัดการชมรมสรรพวาทิต รุ่น 3.5
หน้าเว็บคุยกับ Firebase Realtime Database โดยตรง ความปลอดภัยทั้งหมดอยู่ที่ `database.rules.json` งานที่ต้องมีเซิร์ฟเวอร์ (แจ้งเตือน สำรองข้อมูล) ทำบน Google Apps Script

## ลองใช้ทันที (โหมดสาธิต)

ยังไม่ต้องมี Firebase: เปิดโฟลเดอร์นี้ผ่านเว็บเซิร์ฟเวอร์ใดก็ได้ เช่น `python3 -m http.server 8000` แล้วเข้า `http://localhost:8000` → กดเข้าสู่ระบบ → เลือกบัญชีสมมติ (แอดมิน / ประธาน / ศิษย์ / ผู้รออนุมัติ / ผู้ใช้ใหม่) ข้อมูลเก็บในเบราว์เซอร์นั้นเท่านั้น
เมื่อใส่ค่า Firebase จริงแล้ว ยังเข้าโหมดสาธิตได้ด้วย `index.html?demo=1` และออกด้วย `?demo=0`

## สิ่งที่ระบบทำได้

| หมวด | ความสามารถ |
|---|---|
| เข้าระบบ | บัญชี Google ใดก็ได้ → แบบฟอร์มขอเข้าร่วม → แอดมินอนุมัติ ระบบออกรหัสศิษย์และผูกบัญชี (`accounts/{อีเมล}`) หรือผูกกับชื่อที่แอดมินเพิ่มไว้ก่อน |

| ลิงก์สมัคร | `?join=1` หน้าอธิบายขั้นตอนสมัคร · แอดมินคัดลอก/แชร์ LINE/QR Code และเปิด-ปิดรับสมัครได้ |
| ทำเนียบติดต่อ | ค้นหาตามปีที่เริ่มเรียน จังหวัด ความถนัด · เจ้าตัวเลือกเปิดเผยเบอร์โทร/LINE/อีเมล · ส่งออก DOCX |
| คลังโน้ต | โน้ต ลิงก์ และไฟล์โน้ตของแต่ละทาง เปิดเฉพาะผู้ที่แอดมินอนุญาตเป็นรายเพลง (`noteacc/{sid}/{เพลง}`) · ศิษย์ขอสิทธิ์ได้ · แอดมินให้สิทธิ์รายคน ตามช่วงปีที่เริ่มเรียน หรือผู้ที่ต่อเพลงนั้นแล้ว |
| คลังวิชา | เพลงและทางเพลง + ใครต่อเพลงไหนแล้ว (ศิษย์บันทึก แอดมินยืนยัน) · สายการสืบทอด (สายครู ผังศิษย์หลายชั้น บันทึกพิธีไหว้ครู/ครอบครู ส่งออก PNG/PDF) · คำสอนและผลงานอาจารย์ (ศิษย์ส่ง แอดมินตรวจ) · คลังเอกสาร · ค้นหารวม |
| ประสานงาน | กิจกรรม ปฏิทิน ประกาศ + รับทราบ จัดวง โหวต ข้อความลับถึงแอดมิน การแจ้งเตือนมือถือ กล่องแจ้งเตือน |
| อื่น ๆ | การเงินกองกลาง (ใบรับ/ใบเบิก อนุมัติ) เกียรติบัตร ธรรมเนียมสำนัก ลายเซ็น สำรองข้อมูล คู่มือในแอป |

## นำขึ้นใช้งานจริง (ทำครั้งเดียว)

1. **Firebase** — สร้างโปรเจกต์ใหม่ (แยกจากโปรเจกต์ชมรม) › Realtime Database (asia-southeast1) › Authentication › Sign-in method › เปิด Google › Settings › Authorized domains › เพิ่มโดเมน GitHub Pages
2. **config.js** — วางค่า `firebase` ของ Web app และตรวจ `teacherEmails` · วางค่าเดียวกันใน `firebase-messaging-sw.js`
3. **Rules** — แก้ `BOOT` ใน `tools/build-rules.py` ให้ตรงกับ `teacherEmails` แล้วรัน `python3 tools/build-rules.py` › คัดลอก `database.rules.json` ไปวางที่ Firebase Console › Realtime Database › Rules › Publish
4. **ตรวจ** — `node tools/check.js` ต้องขึ้น “พร้อมเผยแพร่”
5. **GitHub Pages** — สร้าง repo ใหม่ อัปไฟล์ทั้งหมด (ยกเว้นไฟล์กุญแจ) › Settings › Pages › Deploy from branch
6. **การแจ้งเตือน (ไม่บังคับ)** — Firebase › Cloud Messaging › Web Push certificates › Generate key pair → `config.js › vapidKey` · ตั้ง `tools/push-relay.gs` ใน Apps Script ตามคำอธิบายหัวไฟล์ (แก้ `DB` `PROJECT` `APP_URL`) แล้วใส่ URL `/exec` ใน `config.js › pushRelay`
7. เข้าแอปด้วยอีเมลแอดมิน › หน้า “จัดการ”: กด “บันทึกคณะกรรมการ” เพิ่ม อ.อำนาจ และแอดมินท่านอื่น · ส่งลิงก์สมัครเข้ากลุ่ม LINE · คลังวิชา › คำสอนและผลงาน › แก้ประวัติและรูปอาจารย์ · สายการสืบทอด › เพิ่มสายครูจริง

## โครงข้อมูล (สรุป)

ข้อมูลกลาง: `teachers/{อีเมล}` · `accounts/{อีเมล}` = รหัสศิษย์ · `people/{sid}` (ชื่อ รูป fcm) · `privateInfo/{sid}` · `photos/{sid}` · `inbox` `tinbox` `tpush` · `backup/last`
ข้อมูลของสำนัก `c/ss/`: `config` (year instruments advisors bio masterPhoto songCats riteKinds lastSid) · `members/{sid}` (prefix first last nick yearIn type status master inst photo studyNote studied studyAt studyBy) · `roles` · `duties/{sid}/notes` (ผู้เก็บรวบรวมโน้ต) · `requests/{อีเมล}` · `contacts/{sid}` · `songs/{gid}/tang/{tid}` · `notes/{gid}/{tid}` `notefiles/{gid}/{tid}` (โน้ต จำกัดสิทธิ์) · `noteacc/{sid}/{gid}` `notereq/{sid}/{gid}` · `learned/{sid}/{gid}` · `lineage/{id}` · `rites/{sid}/{rid}` · `teach/{id}` · `teachfiles/{id}` · `library` `libfiles` · `y/{ปี}/events announce acks bands ledger counters finsum` · `polls` `ballots` `griev` `awards` `certs` `certidx` `sigs` `public` `pushq` `history`
คีย์อีเมล = อีเมลตัวเล็ก แทน `.` ด้วย `,`

## ออกรุ่นใหม่

1. แก้ `version` / `versionDate` และเพิ่มรายการบนสุดของ `changelog` ใน `config.js`
2. เพิ่มเลข `CACHE` ใน `sw.js` และใส่ไฟล์ใหม่ใน `SHELL` + `<script>` ใน `index.html`
3. ถ้าแก้สิทธิ์: เพิ่ม `RULES_V` ใน `tools/build-rules.py` และ `app.js` ให้ตรงกัน › รัน build-rules › Publish
4. `node tools/check.js` → “พร้อมเผยแพร่” แล้วอัปขึ้น GitHub
